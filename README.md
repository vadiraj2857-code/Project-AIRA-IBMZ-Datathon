# ⚡ Project A.R.I.A. (Artificial Risk & Intelligence Agent)
**IBM Z Datathon — Track 2: AI Secured**

## 📋 Overview
Project A.R.I.A. is an elite, dual-layer cybersecurity and privacy-preserving platform designed for enterprise architectures. It tackles social engineering threats by combining an inbound natural language scam classifier with an outbound PII privacy masker, ensuring zero-exposure compliance and volatile-memory data governance.

## 🛠️ Tech Stack
* **Frontend/UI:** Streamlit (Cyberpunk Neon Theme)
* **NLP & Processing:** SpaCy (`en_core_web_sm`), Python Regular Expressions (`re`)
* **Machine Learning:** Scikit-Learn (TF-IDF Vectorizer & Multinomial Naive Bayes Classifier)
* **Data Visualizations:** Pandas & Altair

## 🖥️ IBM Z / LinuxONE Architectural Alignment
Project A.R.I.A. is engineered to leverage high-throughput, containerized Linux environments on **IBM Z / LinuxONE**. By utilizing hardware-level memory encryption and a zero-persistence execution model, the application processes sensitive workloads securely without writing raw logs to disk.
